# MiniLog JPA

Spring Boot와 JPA를 학습하기 위한 MiniLog 프로젝트입니다.

## 개발 환경

- Java 21
- Spring Boot 3.3.1
- Gradle 8.8
- Ubuntu 24.04 (WSL2)
- IntelliJ IDEA

## 주요 기술

- Spring Boot
- Spring Web
- Spring Data JPA

## 학습 목표

- Spring Boot 기반 웹 애플리케이션 개발
- JPA를 이용한 데이터 영속성 처리
- Spring Boot와 JPA의 기본 구조 이해

## 실행

```bash
./gradlew bootRun
